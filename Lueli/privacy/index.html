광고와 개인정보

Lueli는 Google AdMob으로 비개인 맞춤 광고를 제공합니다. 광고 제공·측정·부정행위 방지와 서비스 개선을 위해 Google이 IP 주소(대략적 위치 추정 포함), 앱·기기 식별 정보, 광고 시청·상호작용 및 충돌·성능 진단 정보를 처리할 수 있습니다. 광고 개인화는 비활성화하며 광고 추적 권한을 요청하지 않습니다. 필요한 지역에서는 광고 동의를 요청하고, 제공되는 경우 앱 설정의 광고 개인정보 설정에서 선택을 바꿀 수 있습니다.

광고 제거와 선택형 보상 광고

광고 제거 결제는 Apple이 처리하며 Lueli는 검증된 구매 내역으로 광고 제거 여부를 확인합니다. 개발자는 결제 카드 정보를 받지 않습니다. 구매 복원으로 같은 Apple 계정의 구매를 다시 적용할 수 있습니다. 광고 제거는 자동으로 표시되는 광고를 제거하며, 포인트가 부족할 때 직접 선택하는 보상 광고는 계속 이용할 수 있습니다. 보상 광고는 완료 확인 시 30P를 지급합니다. 포인트·힌트 해금·중복 보상 방지 기록은 기기에 저장되고 동기화를 선택하면 본인의 iCloud에 저장됩니다.

개발자 서버와 Apple 기능

별도 개발자 계정을 요구하지 않으며 개발자 자체의 플레이 분석 서버를 운영하지 않습니다. 선택한 Game Center·iCloud 및 구매 기능은 Apple이 제공합니다.

기기 저장과 선택적 iCloud 동기화

진행 기록과 음악·효과음·햅틱 설정은 이 기기에 저장됩니다. 설정에서 Game Center 연결을 선택하면 별자리 진행, 최소 횟수, 힌트 사용, 현재 퍼즐과 규칙 설명 확인 기록을 본인의 iCloud에 동기화합니다. 음악과 햅틱 설정은 기기마다 유지됩니다. Apple 계정 식별 정보는 계정 변경을 감지하기 위해 기기에만 보관하며 개발자에게 보내지 않습니다.

기록을 지우는 방법

진행 초기화는 이 기기의 플레이·복구 기록을 지웁니다. 동기화를 켜면 초기화 상태도 다음 연결 때 iCloud에 반영됩니다. 동기화 끄기는 이미 저장된 iCloud 기록을 삭제하지 않습니다. 앱 삭제는 기기 기록만 지우므로 iCloud 연결 시 기록이 복원될 수 있습니다. Apple의 저장·백업·삭제 처리는 사용자의 Apple 설정과 정책에 따릅니다.

문의와 외부 링크

이메일로 문의하면 직접 보내주신 이메일 주소와 문의 내용으로 답변합니다. 문의 내용은 문제 해결과 답변에만 사용하며 해결 후 불필요한 내용은 삭제합니다. 외부 이메일 서비스의 데이터 처리는 해당 서비스의 정책을 따릅니다.
