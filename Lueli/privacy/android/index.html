Android 개인정보처리방침

최종 수정일: 2026년 10월 21일 · 개발자: tricksy bros (TricksyBros)

이 정책은 Google Play에 등록하는 Lueli Android 앱(com.tricksybros.lueli), 버전 1.0.0 빌드 2에 적용됩니다. iPhone·iPad 버전 안내는 별도입니다.

수집하거나 공유하는 앱 데이터

현재 Android 버전은 개인정보를 수집하거나 개발자 또는 제3자에게 전송하지 않습니다. 계정 가입·로그인, 광고·광고 보상, 인앱 결제, 분석·추적 SDK 및 클라우드 동기화가 없습니다. 앱에는 인터넷·위치·연락처·사진·카메라·마이크 접근 권한이 없습니다.

기기에 저장하는 정보

퍼즐 진행, 이동 순서, 최고 기록, 포인트와 힌트 해금 기록, 규칙 설명 확인 여부, 배경음·효과음·햅틱 설정을 앱 전용 기기 저장소에 저장합니다. 이전 버전 저장의 이관·손상 복구용 기록도 기기에만 보관합니다. 포인트는 게임 안의 힌트를 위한 값이며 현금으로 구매·교환·송금할 수 없습니다.

기록을 지우는 방법

앱 설정의 진행 초기화로 완료한 퍼즐·포인트·힌트 기록을 초기화할 수 있습니다. 배경음·효과음·햅틱 설정은 유지됩니다. 모든 로컬 데이터와 설정을 지우려면 Android의 앱 저장공간에서 데이터 삭제를 하거나 앱을 제거하세요. 앱 계정과 개발자 서버 저장이 없어 별도의 계정 삭제 절차는 없습니다. Android 버전은 앱의 시스템 자동 백업을 사용하지 않습니다.

어린이와 이용자

개발자는 이용자의 나이나 신원을 수집하지 않습니다. 앱에는 채팅, 이용자 게시물, 외부 사용자와의 교류 또는 위치 공유 기능이 없습니다.

지원 문의와 외부 서비스

직접 이메일로 문의하면 보내주신 이메일 주소와 문의 내용을 답변과 문제 해결을 위해 처리합니다. 불필요해진 문의 내용은 삭제하며, 사용하는 이메일 서비스의 개인정보 처리에는 해당 서비스의 정책이 적용됩니다. Google Play 또는 Android가 제공하는 별도 시스템 서비스의 데이터 처리는 Google과 사용자의 시스템 설정에 따릅니다.

정책 변경

광고·결제·동기화 등 데이터 처리 방식이 바뀌면 해당 기능을 제공하기 전에 이 정책과 Google Play 데이터 보안 안내를 갱신합니다.

웹페이지

이 안내 페이지에는 분석 도구, 광고, 추적 쿠키 또는 문의 양식이 없습니다. 호스팅 제공자는 웹페이지 전달을 위해 연결 정보를 처리할 수 있습니다.
